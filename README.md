# LakeShore Legends Basketball

Website for LakeShore Legends Basketball: https://www.lakeshorelegendsbasketball.com

## How it's put together

- **Site** — static pages in `docs/`, served by GitHub Pages (`docs/CNAME` sets the domain). DNS is on Cloudflare.
- **Booking backend** — a Cloudflare Worker with a D1 database in `api/`. It handles bookings, Stripe payments, coach logins, settings and family emails (Resend). See `api/DEPLOY.md`.
- **Source vs. output** — page components are written as `docs/js/*.jsx` and compiled into `docs/js/dist/`.
- **`project/`** — an older copy from the original design handoff. The live site is served from `docs/`.

## Changing the site

```
npm install
npm run build        # compile the .jsx files into docs/js/dist
npm run prerender    # bake crawlable text, titles, canonicals, JSON-LD, sitemap.xml, robots.txt, llms.txt
npm run serve        # preview at http://localhost:8080
```

Run `npm run build && npm run prerender` after **any** change to page content or `docs/js/faq.js`, then commit the results. Prerender needs Chrome (set `CHROME_PATH` if it isn't found).

Service prices live in `scripts/prerender.mjs` (`SERVICES`) and `docs/js/faq.js`, and must match Stripe.

`docs/404.html` is a static page (it is not generated by prerender), so keep its header and footer in step with `docs/js/shell.jsx` by hand.

## Booking API

```
cd api
npm test
```

Deploy to the staging server first, then production. Secrets are stored as Worker secrets only. See `api/DEPLOY.md`.

## Never commit

This repository is public. Do not commit API keys, tokens, webhook secrets, `.env` or `.dev.vars` files, or chat transcripts.
